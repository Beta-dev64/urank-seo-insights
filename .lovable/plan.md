# Kredia landing page

## What to build
Replace the Rank homepage shown in the preview with a Kredia landing page about clear credit sales, friendly collections, and stronger distributor relationships. Use the supplied Kredia logo and exact six-color palette, with polished financial-product storytelling inspired by Flutterwave and Mono without copying their layouts.

Keep the defining scroll-led motion: an animated product-led opening, a sticky workflow that advances through invoice, ledger, reminders, payments, and trust score, plus scroll-triggered section reveals and a closing call to action. Ensure the sequence also reads naturally on phones and respects reduced-motion settings.

## Technical approach
Build the page as an isolated React landing-page component and stylesheet; retain the existing import source separately. Use the supplied logo as a Lovable asset, theme colors through project-level semantic CSS variables, and implement scroll progress/state with browser-safe React effects and CSS transforms rather than introducing animation dependencies. Add unique route metadata and document the visual/interaction checks in the observation ledger.

## Verification
Check the homepage at desktop and phone sizes, scrub the workflow in both directions, confirm key content and links remain reachable with reduced motion, inspect browser errors, and check the preview build log.
